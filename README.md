# Secure Password Generation System

## Overview
This project is a Secure Password Generation System developed using Python and Tkinter GUI.

The system generates all possible permutations of characters using:
- Backtracking
- Recursion
- Brute Force

This project demonstrates password analysis techniques used in cybersecurity systems.

---

## Features
- Generate password permutations
- GUI based application
- Password strength checker
- Export passwords to file
- Backtracking implementation
- Brute force implementation

---

## Algorithms Used
1. Backtracking
2. Recursion
3. Brute Force

---

## Time Complexity
O(n!)
